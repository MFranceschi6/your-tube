Duration Short (4 s). Deduplicate: if already visible, reset timer rather than stacking.

Error copy rule Factual, no blame. "Couldn't connect" not "Network error occurred".

Quick-reference — non-negotiable rules

  • Max 1 toast visible at a time. New trigger dismisses the current one and commits any pending Undo.
  • Collapse window: 3 s. Same trigger within 3 s updates the existing toast rather than stacking.
  • Position: bottom edge at safeBottomInset — 152 dp/pt when MiniPlayer visible, 88 dp/pt otherwise.
  • Action label is "Undo" for reversals, "Retry" for failures. Never "Cancel" or "Dismiss".
  • Messages: past tense, ≤50 chars, no trailing period, no emoji, no "Successfully".
  • LiveRegion.Assertive / immediate announcement for errors only. Confirmations use Polite.
  • Action button (Undo/Retry) is never hidden from the accessibility tree.
  • Container colors: Android colorScheme.inverseSurface; iOS #1C1C1E dark surface.
