Privacy. The exported file contains only schemaVersion, id, name, createdAt, updatedAt, and a tracks array (videoId, title, channel, durationSec, thumbnailUrl). No auth tokens, no device IDs, no telemetry IDs. See decision-log § 6.
FileProvider authority. ${applicationId}.sharing.fileprovider, cache-path exports/, declared in AndroidManifest.xml. File is short-lived — cleared on app uninstall and on cache eviction.
Cite, do not redefine. The file format is owned by docs/api-contracts.md. Toast copy lives in toast-catalog/copy.md. The op overlay is state-catalog C15; the inline error styling is C16.
