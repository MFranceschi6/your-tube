What's shown

  • Native .searchable(text:) on the NavigationStack — placement .navigationBarDrawer(displayMode: .always). D1
  • System-provided clear button (xmark.circle.fill) appears when the field is non-blank. D9
  • Chip strip below: 6 chips, recents (clock affordance) first, then curated fillers. D3
  • Selected chip "lofi" renders .buttonStyle(.borderedProminent) with .tint(.accent). D10
  • Results list — top row is the currently-playing track: Color.accent.opacity(0.16) tint, animated EQ overlays the duration badge. D4
  • The EQ indicator's three bars animate via TimelineView(.animation) with phase offsets 0 / 0.2 / 0.4 over a 600 ms period. D4
  • MiniPlayer + TabBar render in their system .regularMaterial Liquid-Glass-ready surfaces.

What it deliberately omits

  • No microphone glyph in the field — voice search deferred (D8). The system keyboard already exposes dictation.
  • No "Clear search history" inline button — that lives in Settings § Data (D6).
  • No custom Liquid Glass surface — the field already participates via system chrome (README §"Liquid Glass on iOS 26+").
  • No skeleton, no error, no offline copy — see mockup-states.html for all nine states.
