  • FAB: production requires ExtendedFloatingActionButton with "New playlist" label; lifts above MiniPlayer via LocalMiniPlayerState — decision Q5 + Q4.
  • Edit mode: production has full in-place edit (drag-handle leading + remove trailing + toast-with-undo) — decision Q3. Long-press contextual sheet stays for read-only.
  • Bottom padding: production uses safeBottomInset from LocalMiniPlayerState, never hardcoded — decision Q4.
  • Single-track remove: production uses Snackbar undo, not a confirm dialog — decision Q3. Confirm dialog is for whole-playlist delete only (Q8).
