YT-0013 · Now Playing · Android

Mockup pointer

This handoff folder does not own a fresh interactive mockup. The legacy combined mockup remains the layout reference:

design-system/mockups/android/YT-0011-0012-0013-shell-search-player.html

Precedence: the markdown in this folder (decision-log.md, compose-spec.md, haptics-and-a11y.md, media3-parity.md) overrides the combined HTML mockup wherever they disagree. The mockup predates the Q1–Q12 decisions and the post-implementation audit at design-system/handoff/YT-0011/audit.md.

Known mockup drift (do not port)

  • Background: mockup uses pal.bg; production uses colorScheme.surface (decision Q3).
  • Scrubber thumb: mockup uses accent purple; production uses white (decision Q4).
  • Play button: mockup uses 64 dp accent circle; production uses 72 dp FilledIconButton with onSurface container / surface content (decision Q5).
  • Queue: mockup is a collapsible inline panel; production is ModalBottomSheet with hand-rolled reorder + SwipeToDismissBox removal (decision Q6).
  • Cast: missing in mockup; production puts MediaRouteButton as the leftmost icon in the action row (decision Q7).
  • MiniPlayer ↔ NowPlaying: mockup has no transition; production uses SharedTransitionLayout + sharedBounds keyed by videoId (decision Q12).
