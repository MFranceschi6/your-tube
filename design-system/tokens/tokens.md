## Motion

### Duration

| Token Name | Value | Usage |
|---|---|---|
| `motion.duration.short` | 150 ms | Fast micro-interactions |
| `motion.duration.standard` | 200 ms | Standard transitions |
| `motion.duration.medium` | 300 ms | Slower transitions |
| `motion.duration.expand` | 320 ms | MiniPlayer → NowPlaying expand |
| `motion.duration.collapse` | 260 ms | NowPlaying → MiniPlayer collapse |
| `motion.duration.reduce-motion` | 120 ms | Both directions under reduce-motion |
| `motion.duration.cross-fade` | 240 ms | Scrim / background cross-fade |

### Easing

| Token Name | Value | Usage |
|---|---|---|
| `motion.easing.standard` | `cubic-bezier(0.2, 0.0, 0.0, 1.0)` | Most transitions (emphasized-decelerate) |
| `motion.easing.exit` | `cubic-bezier(0.3, 0.0, 0.8, 0.15)` | Artwork on collapse (accelerate) |

### Delay

| Token Name | Value | Usage |
|---|---|---|
| `motion.delay.controls-fade-in` | 200 ms | Transport controls fade-in after expand starts |

### Artwork morph

| Token Name | Value | Usage |
|---|---|---|
| `motion.artwork.start-radius` | 4 px | Corner radius at MiniPlayer (= radius.xs) |
| `motion.artwork.end-radius` | 12 px | Corner radius at NowPlaying (= radius.md) |
| `motion.artwork.start-size` | 48 dp | MiniPlayer thumbnail size |
